# HabitTracker

Личный офлайн-трекер привычек для Android. Отмечай выполненные дни и собирай плоскую мозаику по одной клетке за день.

## Скачать

В разделе [Releases](https://github.com/totsamiy02/HabitTracker/releases) у каждого выпуска свой APK. Для **0.0.3** файл называется `HabitTracker-0.0.3-build3.apk`. Нужен Android 8.0 или новее. Установку подтверждает Android.

Если `0.0.1` закрывается при запуске, скачай APK текущей версии и установи поверх из системного установщика.

В приложении можно открыть «Настройки → Обновление приложения» и проверить её наличие. Подписанные релизы устанавливаются поверх предыдущей версии с сохранением данных.

## Что есть в 0.0.3

- Ежедневные отметки, цели по времени и отдельная растущая мозаика для каждой привычки.
- Таймер и секундомер, календарь с повторяющимися планами и напоминаниями, задачи и недельный график.
- Экспорт и восстановление копий в JSON, обновление через GitHub Releases с сохранением данных.

## Сборка и выпуск

Рабочая ветка — `dev`. В `main` попадают проверенные версии. GitHub Actions запускает JVM-тесты, lint, тесты Room и проверку запуска релизного APK на эмуляторе. После успешного прогона на `main` workflow подписывает APK и публикует его в Releases.

Для локальной проверки открой проект в Android Studio с JDK 25 и собери `./gradlew assembleDebug`. Debug-пакет имеет суффикс `.debug`. Ключ подписи хранится вне репозитория.
