# HabitTracker

Личный офлайн-трекер привычек для Android. Отмечай выполненные дни и собирай плоскую мозаику по одной клетке за день.

## Скачать

Скачай APK из [последнего стабильного выпуска](https://github.com/totsamiy02/HabitTracker/releases/latest) или выбери версию в [GitHub Releases](https://github.com/totsamiy02/HabitTracker/releases). Приложение работает на Android 8.0 и новее. Установку подтверждает Android.

Проверить обновление можно в приложении через «Настройки → Обновление приложения». Подписанные APK устанавливаются поверх предыдущей версии с сохранением данных.

## Что нового в 0.0.4

- Экран «Сегодня» показывает планы дня, прогресс привычек и задачи со сроком сегодня. Задачи можно отметить на этом же экране.
- Из связанного плана запускается таймер с паузой и досрочным завершением. Если часть занятия уже записана, кнопка «Ещё» запускает таймер на оставшееся по плану время.
- Сохранённая сессия обновляет минуты в плане и прогресс привычки. При достижении дневной цели закрашивается одна клетка.

## Возможности

- Ежедневные отметки, цели по времени и отдельная растущая мозаика для каждой привычки.
- Таймер и секундомер, календарь с повторяющимися планами и напоминаниями, задачи и недельный график.
- Экспорт и восстановление копий в JSON, обновление через GitHub Releases с сохранением данных.

## Сборка и выпуск

Рабочая ветка — `dev`. В `main` попадают проверенные версии. GitHub Actions запускает JVM-тесты, lint, тесты Room и проверку запуска релизного APK на эмуляторе. После успешного прогона на `main` APK подписывается и публикуется в Releases. [Проверки ветки dev](https://github.com/totsamiy02/HabitTracker/actions/workflows/android.yml?query=branch%3Adev)

Для локальной проверки открой проект в Android Studio с JDK 25 и собери `./gradlew assembleDebug`. Debug-пакет имеет суффикс `.debug`. Ключ подписи хранится вне репозитория.
