# HabitTracker

Личный офлайн-трекер привычек для Android. Отмечай выполненные дни и собирай плоскую мозаику по одной клетке за день.

## Скачать

В разделе [Releases](https://github.com/totsamiy02/HabitTracker/releases) у каждого выпуска свой APK. Для **0.0.2** файл называется `HabitTracker-0.0.2-build2.apk`. Нужен Android 8.0 или новее. Установку подтверждает Android.

Если `0.0.1` закрывается при запуске, скачай APK `0.0.2` и установи поверх из системного установщика.

Когда выйдет следующая версия, в приложении можно открыть «Настройки → Обновление приложения» и проверить её наличие. Подписанные релизы устанавливаются поверх предыдущей версии с сохранением данных.

## Что есть в 0.0.2

- Создание ежедневных привычек с названием и описанием.
- Отметка за день, отдельная мозаика для каждой привычки и хранение данных на телефоне.
- Экспорт резервной копии в JSON и проверка обновлений.

## Сборка и выпуск

Рабочая ветка — `dev`. В `main` попадают проверенные версии. GitHub Actions запускает JVM-тесты, lint, тесты Room и проверку запуска релизного APK на эмуляторе. После успешного прогона на `main` workflow подписывает APK и публикует его в Releases.

Для локальной проверки открой проект в Android Studio с JDK 25 и собери `./gradlew assembleDebug`. Debug-пакет имеет суффикс `.debug`. Ключ подписи хранится вне репозитория.
