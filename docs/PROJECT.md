# HabitTracker

Личный офлайн-трекер привычек для Android. Один выполненный день добавляет привычке одну клетку. Клетки образуют плоскую квадратную мозаику. Пропуски сохраняют собранный рисунок.

## Что реализовано

- Один модуль `:app`, Kotlin, Jetpack Compose, Material 3, палитра и логотип «Слива и лаванда». Минимальная версия Android — API 26. Строки интерфейса на русском хранятся в ресурсах. Постоянный `applicationId` — `com.yaroslav.habittracker`, у debug есть суффикс `.debug`.
- **Сегодня** — текущая локальная дата, активный таймер, планы дня, привычки и задачи со сроком сегодня. Таймер запускается из связанного плана, показывается над списком и управляется на том же экране. Длительность берётся из плана. После неполной сессии кнопка «Ещё» запускает отсчёт на остаток. Если длительность не указана, учитывается остаток дневной цели или используются 25 минут. Карточка плана показывает фактическое время сессий с тем же планом за дату экрана. Задача отмечается в общей базе. Прогресс и клетка обновляются из истории после сохранения сессии.
- **Привычки** — название, описание, расписание по дням недели и настраиваемая цель по времени. Простые привычки отмечаются по одной или группой. В истории можно менять дату отметки, удалять её, добавлять и исправлять время. Для цели по времени складывается длительность за локальную дату. За день начисляется максимум одна клетка. Сохранённые отметки учитываются при смене типа привычки.
- **График** — общий календарь рабочих смен, личных планов и фактических записей с фильтрами. Дни отмечены дневными, ночными сменами и продолжениями за полночь. У смены есть плановые часы, перерыв, необязательная ставка в рублях и фактические часы после подтверждения. Дневной и ночной шаблоны встроены, свои шаблоны можно сохранять и менять. Созданная смена хранит собственные значения. Отчёты разделяют план и факт за месяц, год и выбранные даты. Часы и заработок всей смены относятся к дате её начала. Перерыв вычитается из оплачиваемого времени, сумма округляется до копейки, отсутствие ставки отмечается в отчёте.
- **Личные планы** — дата, время, необязательная длительность и связь с привычкой. Из связанного плана открывается таймер. Повторы поддерживают каждый день, будни и выбранные дни. Изменение одного занятия создаёт исключение, изменение серии разделяет её с выбранной даты. Фактические сессии остаются на своих датах. Напоминания используют системный будильник и отдельный канал уведомлений. Android может задержать напоминание, если точные будильники недоступны.
- **Задачи** — отдельная вкладка с простыми задачами, необязательным сроком и фильтрами по статусу.
- **Недельная статистика** — открывается с экрана «Сегодня». План складывает длительности событий с учётом повторов и исключений. Факт суммирует сессии за их даты, включая ручной ввод. Одна сессия считается один раз, даже если связана с несколькими привычками.
- **Мозаика** — Compose Canvas строит отдельный рисунок для каждой привычки по числу выполненных дней. Квадрат начинается с 4 × 4. На 17-й выполненный день справа и снизу появляются новые клетки, а прежние координаты сохраняются. История независима от шаблона.
- **Фокус** — один активный обратный отсчёт или секундомер. Сессию можно связать с несколькими привычками, приостановить, продолжить или завершить с сохранением фактического времени. Room хранит активное состояние. Поправка на монотонные часы сохраняет точный отсчёт при сворачивании и блокировке. Сервис ведёт уведомление с действиями и завершает отсчёт в фоне вместе с системным будильником. Транзакция сохраняет сессию, связи и закрывает активный таймер. В публичном уведомлении на экране блокировки имена привычек скрыты.
- **Данные и настройки** — миграции Room 1 → 2 → 3 → 4 → 5 сохраняют существующие записи. Экспорт через системный выбор файла сохраняет согласованный снимок JSON формата 5, включая задачи, исключения повторов, параметры мозаики, смены и шаблоны. Восстановление читает форматы 1–5, показывает состав копии рядом с текущими данными и запрашивает подтверждение замены. Замена выполняется одной транзакцией после завершения активного таймера. Повреждённая или неподдерживаемая копия отклоняется до записи. Системное резервное копирование отключено.
- **Обновления** — приложение проверяет последний стабильный GitHub Release `totsamiy02/HabitTracker`. Тег имеет вид `v<versionName>`, файл — `HabitTracker-<versionName>-build<versionCode>.apk`. Клиент сравнивает `versionCode`, а релизная сборка проверяет пакет, версию и подпись скачанного APK перед открытием системного установщика.

Код разделён на `habits/`, `calendar/`, `planning/`, `work/`, `tasks/`, `timer/`, `today/`, `settings/` и `ui/` в пакете `com.yaroslav.habittracker`. Экспорт схемы Room хранится в `app/schemas/`. Рабочая ветка — `dev`, стабильная — `main`. Журнал — [CHANGELOG.md](CHANGELOG.md). Визуальные черновики храним вне репозитория.

Коммиты создаются в GitHub в ветке `dev`. GitHub Actions из `.github/workflows/android.yml` запускает JVM-тесты, lint, тесты Room и проверку запуска APK с тестовым ключом. Релизный коммит связывает номер версии в Gradle, README и запись в журнале. После зелёного прогона этого коммита в `dev` тот же SHA отправляется в `main`. Actions повторяет проверки, подписывает APK и публикует его в GitHub Releases с описанием из журнала. Оптимизация R8 отключена после сбоя запуска с ограниченной областью оптимизации. Ключ хранится вне репозитория, CI получает его из GitHub Secrets.

## Рабочие ограничения

Бюджет 0 ₽. Основные функции работают офлайн, сеть нужна для обновлений. Приложение обходится без аккаунта, сервера и Google Play. Сборка на Mac через Gradle Wrapper с JDK Android Studio, APK проверяется вручную на телефоне. Для отдельных компонентов подходит Compose Preview.

Перед работой используй [правила разработки](CHAT_PROMPT.md). Актуализируй существующие разделы при изменении поведения или архитектуры. Историю выпусков держи отдельно.
