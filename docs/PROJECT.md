# HabitTracker

Личный офлайн-трекер привычек для Android. Каждый выполненный день даёт привычке одну закрашенную клетку. Из клеток постепенно складывается плоская квадратная мозаика, которая расширяется по мере накопления выполненных дней. Пропуски видны в календаре и не стирают накопленный прогресс.

## Текущее состояние

- Открыт проект Android Studio из шаблона Empty Activity для Compose. Один модуль `:app`. Идентификатор приложения `com.yaroslav.habittracker`, минимальная версия Android — API 26.
- Базовый `assembleDebug` прошёл с JDK из Android Studio. В приложении пока экран шаблона. В Git пока нет коммитов и удалённого репозитория. Рабочая отметка версии — 0.0.1, журнал ведётся в [CHANGELOG.md](CHANGELOG.md).
- Согласована палитра «Слива и лаванда»: светлый лавандовый фон, сливовый текст и фиолетовый акцент. Первый сценарий включает две вкладки. В «Сегодня» создаём привычку, отмечаем день и видим клетку плоской мозаики. В «Настройках» показываем логотип, описание, версию, обновление приложения и экспорт резервной копии. Визуальные черновики храним вне репозитория. К реализации переходим по явной команде пользователя.

## Первая рабочая версия

- **Привычки** — создание и редактирование названия, необязательного описания и расписания, история и исправление записей. В макете простую привычку закрывают нажатием на следующую клетку или кнопкой «Отметить сегодня», привычку с целью по времени — суммой сессий за день. При неполной цели виден прогресс, например «90 / 120 мин». На один выполненный день приходится одна клетка.
- **Таймер** — ручной запуск из привычки или связанного плана, обратный отсчёт, пауза, продолжение и досрочное завершение с сохранением фактического времени. После сворачивания или блокировки восстанавливается правильное состояние. Каждая завершённая сессия один раз попадает в историю и календарь. Время можно внести вручную.
- **Экраны** — «Сегодня» показывает привычки, прогресс и планы. «Календарь» показывает планы и фактические записи выбранной даты. «Привычки» содержит список, настройки привычек, историю и рисунки. «Настройки» содержит резервные копии, блокировку и обновления. Активный таймер доступен с основных экранов.
- **Рисунок** — отдельная плоская квадратная мозаика для каждой привычки, рисуется через Compose Canvas. В макете квадрат начинается с 4 × 4 клеток. После заполнения по правому и нижнему краям добавляются столбец и ряд, а прежние клетки сохраняют положение. На 17-й выполненный день прогресс составляет 17 из 25. История хранится отдельно от рисунка.
- **Резервная копия** — один версионированный файл через системный выбор файлов. Включает привычки, отметки, сессии, планы и данные рисунков. Перед заменой данных показываем состав копии и запрашиваем подтверждение. Проверяем файл до записи в базу. Блокировка приложения опциональна и использует биометрию или системный PIN.
- **Обновления** — рабочая ветка `dev`, стабильная `main`. Пуш в `main` запускает проверки, сборку подписанного APK и публикацию стабильного релиза через GitHub Actions. Приложение показывает новую версию и описание, скачивает APK и открывает системный установщик. Для обновления поверх текущей версии нужны тот же идентификатор, тот же ключ и больший `versionCode`. Ключ хранится вне репозитория, для CI используются GitHub Secrets. Для ключа нужна отдельная резервная копия. Изменения схемы Room требуют миграций с сохранением данных.

## Стек и проверка

Kotlin, Jetpack Compose, Material 3, Compose Canvas, Room/SQLite, DataStore, Gradle Wrapper. В одном модуле разделяем код по функциям. Интерфейс на русском, пользовательские строки в ресурсах. Бюджет 0 ₽. Основные функции работают офлайн, интернет нужен для обновлений. Без аккаунта, сервера и публикации в Google Play. Для CI планируется публичный репозиторий, личные записи и копии остаются у пользователя.

Первый сценарий после согласования дизайна — создать простую привычку, отметить её на экране «Сегодня», увидеть клетку и проверить сохранение после перезапуска. Сборка на Mac, APK переносится на телефон для ручной проверки. Для отдельных компонентов можно использовать Compose Preview. Перед постоянным использованием проверяем на телефоне два подписанных APK: создаём записи в первом, устанавливаем второй из GitHub кнопкой обновления и сверяем данные.
