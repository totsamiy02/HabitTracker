# Журнал версий HabitTracker

## 0.0.1 — подготовка

Рабочая отметка проекта. Релиз в GitHub ещё не опубликован.

- Проверены настройки проекта и базовая сборка debug APK.
- Записаны концепт, требования первой версии и сценарий ручной проверки.

## Ведение журнала

Для следующих изменений готовим краткую запись в `dev`. Каждый пуш в `main` должен выпускать новую версию с большим `versionCode`. После публикации фиксируем дату, `versionName`, `versionCode`, ссылку на GitHub Release и заметные изменения. При изменении схемы базы указываем миграцию и результат проверки обновления поверх предыдущего APK. Пока процесс выпуска не настроен.
